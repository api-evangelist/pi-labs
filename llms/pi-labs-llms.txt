# Pi Labs

> Pi Labs (withpi.ai) is an applied-AI company, backed by Accel and later acquired by Microsoft, that builds tools to evaluate and enhance AI applications. Its core product is Pi Scorer — a deterministic, ~200ms foundation-model scorer that judges any text against a rubric of natural-language questions (500x more efficient than LLM-as-a-judge) — exposed as an OpenAPI-compatible REST API with official Python and TypeScript SDKs.

## APIs

- [Pi Scoring API](https://code.withpi.ai): OpenAPI-compatible REST API at https://api.withpi.ai for scoring, calibrating, and optimizing LLM outputs against rubrics. API-key auth via the WITHPI_API_KEY header.

## SDKs

- [withpi (Python)](https://pypi.org/project/withpi/): Official Python SDK — `pip install withpi`, sync + async clients (httpx).
- [withpi (TypeScript)](https://www.npmjs.com/package/withpi): Official TypeScript/Node SDK — `npm install withpi`.
